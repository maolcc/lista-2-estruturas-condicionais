# Lista 2 - Estruturas Condicionais

**Curso:** Engenharia de Software  
**Semestre:** 2º semestre  
**Linguagem:** C

## Sobre a atividade

Esta é a segunda lista de exercícios da disciplina de programação.  
Os exercícios foram desenvolvidos em C com foco em estruturas condicionais e na prática de entrada, processamento e saída de dados.

## Exercícios

1. Verificar se a soma de A + B é menor que C.
2. Ler dados de uma pessoa e, quando necessário, informar o tempo de casamento.
3. Verificar se um número é par ou ímpar.
4. Somar números iguais ou multiplicar números diferentes.
5. Calcular o dobro de um número positivo ou o triplo de um número negativo.
6. Verificar dois valores lógicos.
7. Somar 5 a números pares e 8 a números ímpares.
8. Apresentar três números em ordem decrescente.
9. Calcular o peso ideal.
10. Calcular e classificar o IMC.
11. Calcular o valor final de um produto de acordo com a forma de pagamento.
12. Calcular a média de aproveitamento e o conceito do aluno.
13. Classificar uma infração de trânsito de acordo com o percentual excedido.
14. Apresentar um cardápio utilizando `switch`.
